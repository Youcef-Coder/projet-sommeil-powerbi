# projet-sommeil-powerbi
Description:
Projet d'analyse exploratoire visant à identifier les facteurs influençant la qualité du sommeil à partir d'un jeu de données public. L'analyse a été réalisée avec Power BI et a permis d'étudier l'impact de la durée du sommeil, du niveau de stress, de l'activité physique, de l'âge, de la profession et des troubles du sommeil.
